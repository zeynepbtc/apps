# Onboarding R2-A — İçerik Doğruluğu + Kesin Metin (B2) · KİLİTLİ

> **Durum:** KİLİTLİ (Zeynep). Tüm ekran metinleri + doğruluk kuralları onaylı. **Kod YOK.** Kaynak akış: `ONBOARDING-B2-akis-haritasi.md`. Ana kaynak: **Japan Foundation (国際交流基金) + NINJAL (国立国語研究所).**
> **Tek küçük varsayım:** Karşılama başlığı = kesin Store/ürün adı **"Kanji Atlas"**. Store adı farklı olursa yalnız bu başlık değişir.

---

## §A — Doğrulanmış dilbilgisi gerçekleri (iç gerçek; onboarding yüzeyinde görünmez)

| # | İç gerçek | Yüzey kuralı |
|---|---|---|
| **A1** | Japoncanın ritmik ses yapısı **mora temellidir**. Kana yazısı bu ses yapısını gösterir; **ancak her görünen kana tek başına bir moraya birebir karşılık gelmez** (しゃ = iki kana, tek ritmik birim/mora; uzun ses, küçük っ, ん mora sayımında özel davranır). | Onboarding'de **ne "mora" ne "hece"**. En güvenli çerçeve: *"Japoncadaki sesleri yazmak için kullanılır."* |
| **A2** | Hiragana: Japonca sözcükler + dil bilgisi ekleri. | Ekran 3 metni (§C). |
| **A3** | Katakana: hiragana ile aynı sesler; ağırlıkla yabancı kökenli sözcük, ad, ses taklidi. | Ekran 3 metni. |
| **A4** | Kanji: anlamla ilişkili; okunuş **kelime bağlamına göre değişir** (aynı kanji birden çok okunuş). Tek başına soyut "kavram işareti" olarak sunulmaz. | Ekran 3 metni: "okunuşu bulunduğu kelimeye göre değişebilir". |

---

## §B — Yasak / güvenli ifade kuralları

**Yasak yüzey ifadeleri:** "sembollere hece denir" · "kana = hece" · "her kana bir moraya karşılık gelir" · "her işaret bir sesi temsil eder" · "her kanji bir kavramı gösterir" · "kanji ses değil anlam taşır" / "ses taşımaz" · "üç yazı sisteminden oluşur" (mutlaklık) · **"mora"** (onboarding'de hiç geçmez).

**Diğer:** Terminoloji yüzeyde *bileşen · parça · aile · ortak yapı*; "radikal" yalnız sözlük radikali. Ton sakin/abartısız, ürün temel/N5. **"İlk harfin/karakterin" yerine doğrudan あ** (kana Latin harfiyle birebir aynı kavram değil). Hitap: her yerde **"sen"**.

**Mora — ileri iş (onboarding değil):** İsteğe bağlı derin bilgi kartı *"Meraklısına: Japoncanın ritmi"* — mora, uzun sesler, ん, küçük っ, きゃ örnekleri. İlk Kana dersinde bile zorunlu tanım değil.

## §C — Kesin metin (ekran-ekran) · KİLİTLİ

### Ekran 1 — Karşılama
```
Başlık:    Kanji Atlas            (= kesin Store/ürün adı)
Alt cümle: Japonca yazının mantığını adım adım keşfet.
Birincil:  Başlayalım
İkincil:   Ana sayfaya geç
```

### Ekran 2 — Yetkinlik (tek karar)
```
Başlık:    Japonca yazıda nereden başlıyorsun?
Alt cümle: Sana uygun bir başlangıç önerelim.

Band 0:    Japonca yazıya hiç başlamadım
Band 1:    Birkaç temel karakter tanıyorum
Band 2:    Hiragana ve katakana okuyabiliyorum
Band 3:    Hiragana, katakana ve bazı kanjileri biliyorum

İkincil:   Ana sayfaya geç
```
İki satıra izin veren düzende (R3 kararı) opsiyonel alt satırlar: Band 0 → "Japonca yazıya yeniyim." · Band 1 → "あ, か, ア gibi." Not: "kana" kelimesi seçeneklerde **kullanılmaz** (kullanıcı henüz öğrenmedi).

### Ekran 3 — Üç Yazı Sistemi (yalnız Band 0/1)
```
Başlık:  Japonca yazıda üç ana sistem birlikte kullanılır.

あ  Hiragana
    Japonca sözcüklerde ve dilbilgisi eklerinde sık kullanılır.

ア  Katakana
    Hiragana ile aynı sesleri yazar; çoğunlukla yabancı kökenli
    sözcüklerde, adlarda ve ses taklitlerinde kullanılır.

火  Kanji
    Anlamla ilişkili karakterlerdir. Bir kanjinin okunuşu,
    bulunduğu kelimeye göre değişebilir.

Köprü:    Temel sesleri tanımak, sonraki adımları kolaylaştırır.
Birincil: Devam
İkincil:  Ana sayfaya geç          (Band 1'de ayrı "bu ekranı geç" YOK)
```
Not: "ikiz sistem" temel tanımda **kullanılmaz** (eğitim metninde oyuncak kalıyor); istenirse ayrı yardım kartında.

### Ekran 4 — Dürüst Öneri / Final (bant bant)

**Band 0 — Rehberli あ detayı**
```
Başlık:   あ ile başlayalım.
Gerekçe:  Önce sesini dinle ve şeklini tanı. Hazır olduğunda yazmayı dene.
Birincil: あ ile başla
İkincil:  Ana sayfaya git
```

**Band 1 — Kana ana görünümü**
```
Başlık:   Temel karakterlerden devam et.
Gerekçe:  Tanıdıklarını gözden geçir, eksiklerini seçerek ilerle.
Birincil: Kana bölümünü aç
İkincil:  Ana sayfaya git
```

**Band 2 — İlk kanji ailesi / 木**
```
Başlık:   Kanji yapılarına geçmeye hazırsın.
Hedef:    İlk kanji ailesi: 木
Gerekçe:  Ortak parçaları izleyerek kanjiler arasındaki bağlantıları keşfet.
Birincil: 木 ailesiyle başla
İkincil:  Ana sayfaya git
```

**Band 3 — Atlas**
```
Başlık:   Atlas'tan devam et.
Gerekçe:  Kanjiler arasındaki bağlantıları keşfet ve istediğin noktadan ilerle.
Birincil: Atlas'ı aç
İkincil:  Ana sayfaya git
```

### Skipped Home (bant seçmeden "Ana sayfaya geç")
```
Kişiselleştirilmiş öneri şeridi:  gösterilmez
Genel/nötr öneri şeridi:          konmaz  ("Nereden başlamak istersin, seç." YOK)
Gösterilen:  yalnız eşit ağırlıklı ana modül kartları (Home'un normal hali)
```
İlk anlamlı öğrenme eyleminden sonra `recommendedNext` için gerçek veri oluşur.

### Mikrokopi — kaçış tutarlılığı
```
Ara ekranlar (Karşılama/Yetkinlik/Üç-sistem): Ana sayfaya geç
Final ikincil eylem:                          Ana sayfaya git
```
