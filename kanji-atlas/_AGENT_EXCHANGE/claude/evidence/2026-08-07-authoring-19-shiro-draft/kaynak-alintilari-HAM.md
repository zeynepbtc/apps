Başlık karakteri **白** doğrulandı; üstveri kayıtla uyumlu:

```
部首   : 白
画数   : 5
音読み : ハク・ビャク
訓読み : しろ・しら・しろい
意味   : ①しろ。しろい。「白衣」「紅白」  ②きよい。けがれがない。「潔白」
         ③しろくする。しらげる。「精白」「漂白」  ④あかるい。あきらか。はっきりしている。「白日」「明白」
         ⑤なにもない。「白紙」「空白」  ⑥もうす。告げる。「白状」「建白」  ⑦せりふ。「科白」
```

### 字源・成り立ち (özgün metin)

```
象形。白骨化した頭骨の形にかたどる。もと、されこうべの意を表した。
転じて「しろい」、借りて、あきらか、「もうす」意に用いる。
```

Okunuşu: 象形 · **白骨化した頭骨** (beyazlaşmış kafatası) biçimi · asıl anlamı **されこうべ**
(kafatası) · "しろい" (beyaz) anlamına **転じて** (anlam kayması) · "aydınlık" ve "söylemek"
anlamlarına ise **借りて** (ödünç).

> Not: ESAS burada iki mekanizmayı **ayırıyor** — beyaz için 転じて, diğer anlamlar için 借りて.
> Bu ayrım matriste korunmuştur.

### 説文解字注 (段玉裁) — **AYRI KATMAN**

```
(白)西方色也。侌用事。物色白。从入合二。出者陽也，入者陰也，故从入。
二，侌數。說从二之恉。旁陌切。古音在五部。凡白之屬皆从白。
(𦣺)古文白。
```

### 康熙字典 — **AYRI KATMAN**

```
【午集中】【白字部】康熙笔画：5
〔古文〕𦣺𤼽【唐韻】旁陌切【集韻】【韻會】【正韻】薄陌切，𠀤音帛。
【說文】西方色也。隂用事，物色白。从入合二，二隂數也。
```

Okunuşu: **nesne verilmiyor.** 説文 白'ı "batının rengi" olarak tanımlayıp 五行 kozmolojisiyle
açıklıyor ve mühür biçimini yapısal olarak çözümlüyor (入 + 二). Anlam zaten "beyaz"tan
başlıyor; biçimden anlama geçiş anlatılmıyor.

### 漢典 · 詳細解释 (geleneksel sözlük satırı, **AYRI KATMAN**)

```
象形。甲骨文字形，象日光上下射之形，太阳之明为白
```

Okunuşu: 甲骨文 biçimi **yukarı ve aşağı yayılan gün ışığını** gösterir; güneşin parlaklığı
"beyaz"dır. → **gün doğumu/ışık teorisi**, ESAS'ın kafatası teorisiyle bağdaşmaz.

`字源字形` bölümünde biçim dizisi var; **甲骨文 için modern akademik yorum paragrafı yok**
