
### 説文解字注 (段玉裁)

```
(今)是時也。今者對古之偁。古不一其時。今亦不一其時也。云是時者。如言目前。
則目前爲今。目前已上皆古。……从亼乀。會意。乀、逮也。乀亦聲。居音切。七部。
乀、古文及。見又部。
```

### 康熙字典 (aynı sayfadan)

```
从亼𠃌會意。𠃌，古文及字。巳往爲古，逮及爲今。
```

Okunuşu: **nesne verilmiyor**; mühür biçiminin yapısal çözümlemesi (亼 + 乁/及). Oluşum türü
段注'ya göre **会意** (乀 aynı zamanda ses bileşeni). Anlam mekanizması: 逮及 (erişmek/ulaşmak)
→ "şu an"; 巳往爲古、逮及爲今 karşıtlığı.

Aynı sayfada 甲骨文 · 金文 · 楚系簡帛 · 說文小篆 · 秦系簡牘 · 隸書 · 楷書 biçim dizisi var;
**甲骨文 biçimleri için modern akademik bir yorum notu sayfada yok** (35 biçim örneği listeleniyor).
